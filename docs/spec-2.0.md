# Сайт-лента · движок и админка · спецификация 2.0

Версия 2.0 от 06.10.2026. Владелец: Вячеслав. Разработчик: Вадим.
Заменяет спецификацию 1.4 (она уходит в архив).

## 0. Как читать

- Движок по 1.4 уже во многом сделан. Эта спецификация говорит, **что изменить** в готовом коде, а не как строить с нуля.
- Раздел 1 — список изменений. Начинать с него.
- Где написано «как в 1.4» — поведение не меняется, код не трогать.
- Если спецификация и макет расходятся, права спецификация.
- Любое изменение базы — только новой миграцией. Старые миграции не редактировать.

## 1. Что изменилось по сравнению с 1.4

| № | Было в 1.4 | Стало в 2.0 |
| --- | --- | --- |
| 1 | Предисловие и Послесловие, по одному на уровень | Один блок **Текст**, сколько угодно, в любом месте |
| 2 | Фото внутри Предисловия | Отдельный блок **Фото** |
| 3 | Плитки — отдельные элементы, сетка собиралась сама | Блок **Плитки** — контейнер с настройками, плитки внутри него |
| 4 | Элемент «Вино» | Вид блока Плитки: «вина» |
| 5 | Режим сайта «Простой / С табами» | Блок **Табы**. Есть блок — есть табы. Настройка `site_mode` отменена |
| 6 | Переключатель «Открыть страницу / карточку» | Автоматически + галочка «Открывать как страницу» |
| 7 | Кнопки «Открыть раздел» / «Подробнее» или стрелка | Значок в углу плитки: **→** страница, **+** поп-ап |
| 8 | Источник фото выводится в карточке | Не выводится и не показывается в админке |
| 9 | SEO-тексты только автоматически | Поля «Для поисковиков» у страниц и плиток |
| 10 | Выгрузка одного раздела | Выгрузка всего сайта + «Только структура» + выгрузка таба |

Остаётся как в 1.4: Шапка, Подвал, Карта, Оплата и окно оплаты, Услуга, способы оплаты, реквизиты RU/GE, владельцы, документы, cookies, адреса (домены), поп-ап карточки («‹ К списку», «Как добраться», мини-карта), редактор фото, превью, сохранение, миграции.

## 2. Принципы (не менялись)

1. Контент только в базе. Служебные подписи — в `lang/ru.php`.
2. Два уровня. Глубже нельзя.
3. Один рендер для сайта и превью.
4. Сайт работает без JS. JS только улучшает.
5. PHP 8.1+, SQLite, ванильный JS. Leaflet, Cropper.js — локально.
6. Тексты в базе с кодом языка. В v1 один язык (ru). Все новые текстовые поля 2.0 (надзаголовок, подзаголовок, подпись к фото, «Для поисковиков» и др.) хранить только с кодом языка — в `element_i18n` или `settings_i18n`, не в общих таблицах. Переключатель языков — этап 2.
7. Сайт без «Купить» и корзины. Оплата — только ссылками и реквизитами.

## 3. Уровни и открытие плиток

**Уровень 1** — главная (или лента таба).
**Уровень 2** — страница плитки.
**Поп-ап** — окно поверх страницы. Это не уровень.

Как открывается плитка уровня 1:

| Внутри плитки | Галочка «Открывать как страницу» | Открывается | Значок |
| --- | --- | --- | --- |
| нет блоков | нет | поп-ап | + |
| нет блоков | да | статичная страница | → |
| есть блоки | не важно | страница | → |

Плитка уровня 2 — всегда поп-ап, значок +. Галочки у неё нет.

Если у плитки нечего показать в поп-апе (нет текста и нет «Как добраться»), значка нет и плитка не нажимается.

**Статичная страница** — верх страницы из самой плитки (фото, название, текст, «Как добраться» с мини-картой), без блоков ниже. Верх страницы с блоками собирается так же, блоки идут ниже. Как в 1.4, раздел А4.

## 4. Один набор блоков

Главная, лента таба и страница плитки собираются из одного набора блоков.

Пример. На главной плитка «Апостол Андрей». На её странице: блок Текст (описание), блок Плитки (5 мест), Карта (точки маршрута).

| Блок | Сколько | Где |
| --- | --- | --- |
| Шапка | 1 на сайт | на всех страницах |
| Подвал | 1 на сайт | на всех страницах |
| Табы | 1 на сайт | только главная, последним блоком |
| Карта | 1 на страницу | любое место |
| Оплата | 1 на страницу | любое место |
| Текст, Фото, Плитки, Услуга | сколько угодно | любое место |

На странице плитки (уровень 2) нельзя: Табы, плитку с галочкой «Открывать как страницу».

## 5. Блоки

### 5.1 Шапка — как в 1.4

Название сайта (40) · меню: авто / всегда / нет · показать / скрыть.

### 5.2 Текст (новый, заменяет Предисловие и Послесловие)

| Поле | Макс. знаков | Варианты |
| --- | --- | --- |
| Надзаголовок | 40 | — |
| Заголовок | 60 | размер: крупно / обычно / мелко (по умолчанию: обычно) |
| Подзаголовок | 120 | — |
| Текст | 3000 | размер: вводный / обычный / мелкий (по умолчанию: обычный) |

- Все поля необязательные. Пустое поле не выводится.
- Размеры — только эти готовые варианты. Значения — переменные в `theme.css`.
- Переносы строк в тексте = абзацы. Разметки (жирный и т. п.) нет.
- Первый блок Текст на главной даёт `<h1>` (его заголовок). Остальные заголовки — `<h2>`.

### 5.3 Фото (новый)

| Поле | Значение |
| --- | --- |
| Фото | 3:2, редактор фото как в 1.4 |
| Подпись | до 120 знаков, необязательно |
| Ширина | на всю ширину (по умолчанию) / узкое по центру (около 50 % колонки, на телефоне на всю ширину) |

Выравнивания влево и вправо нет. Текст рядом с фото не ставится.

### 5.4 Табы (новый, заменяет режим сайта)

Нужен для агрегатора: страны → монастыри → страница монастыря.

- Один на сайт. Только на главной. Всегда последний блок главной.
- Блоки **выше** Табов — общие для всех стран (бывшее «Общее предисловие»).
- У каждого таба:
  - Название (30) и slug (40, как в 1.4);
  - своя лента блоков (Текст, Фото, Плитки, Карта, Оплата, Услуга);
  - настройки страны: валюта, владелец, формат реквизитов (RU / GE / другой), сервис карт (Google / Яндекс), «Показывать цены вин», адрес сайта страны.
- Показать / скрыть таб.
- Под капотом таб = раздел из 1.4 (`sections`). Поведение на сайте — как в 1.4, разделы А1, А2а, 9:
  - «пилюли» по центру со счётчиком плиток;
  - адреса `/{таб}/…`;
  - переключение без перезагрузки, «Назад» браузера работает;
  - бейдж страны на плитке;
  - карта главной — по активному табу; кластеризация при > 30 отметок;
  - адрес страны (например, georgia.…) показывает один таб без табов и без общих блоков.
- Нет блока Табы — сайт работает с одной лентой, адреса без префикса.

### 5.5 Плитки (новый контейнер)

Настройки блока:

| Настройка | Варианты |
| --- | --- |
| Размер | крупные: 3 / 2 / 1 в ряд (компьютер / планшет / телефон) · компактные: 4 / 3 / 2 |
| Фото | горизонтальное 3:2 · вертикальное 4:5 |
| Вид | обычные · вина |

- Все плитки внутри блока одного размера и формата.
- Нужны плитки разного вида — два блока Плитки подряд.

Поля плитки:

| Поле | Макс. знаков |
| --- | --- |
| Фото | рамка по настройке блока |
| Название | 45 |
| Подпись | 90 |
| Текст | 3000 |
| Как добраться | 140 |
| Широта, долгота | десятичные градусы |
| Открывать как страницу | галочка, только уровень 1 |
| Для поисковиков: заголовок / описание | 60 / 160 |

Вид плитки на сайте:

- Фото, под ним плашка: название, подпись, значок.
- Значок — в правом нижнем углу плашки: **→** (страница) или **+** (поп-ап).
- Все плитки в ряду одной высоты. Значок прибит к низу и всегда на одной линии в ряду.
- Название — не больше 2 строк, подпись — не больше 2 строк, дальше многоточие. Полный текст — в поп-апе или на странице.
- Вся плитка — одна ссылка `<a href>` на адрес страницы или поп-апа.
- Без фото — только плашка.

Плитка-вино (вид блока «вина») — дополнительные поля:

| Поле | Значение |
| --- | --- |
| Сорт | до 60 знаков |
| Год урожая | число |
| Цвет | красное / белое / розовое / янтарное |
| Сладость | сухое / полусухое / полусладкое / сладкое |
| Цена | число, валюта таба; показывается, если включено «Показывать цены вин» |

- Вино открывается только поп-апом. Галочки «как страницу» нет.
- Без текста (описания) вино не нажимается.
- Без фото — силуэт бутылки.
- Кнопок «Купить», «В корзину» нет.
- Набор полей вина — сверить с проектом Вадима. Если у него поля другие, берутся его.

### 5.6 Карта — как в 1.4

Заголовок (60). Точки ставятся сами из видимых плиток с координатами (и поп-апы, и страницы). На главной — все точки ленты (или активного таба) и их страниц; на странице плитки — точки этой страницы. Нет точек — блок не выводится.

### 5.7 Оплата — как в 1.4

Одна на страницу. Заголовок, текст, кнопка, «Кому идут деньги», способы оплаты списком (QR, ссылки, реквизиты по формату таба).

### 5.8 Услуга — как в 1.4

Заголовок (60), текст (500), цена, подпись к цене, кнопка-ссылка на оплату. Без ссылки не выводится.

### 5.9 Подвал — как в 1.4

Почта, телефон, соцсети, реквизиты владельца, ссылки на документы.

## 6. Поп-ап плитки — как в 1.4 (раздел А6), одно изменение

Строка «Фото: …» (источник фото) **больше не выводится**.

## 7. Для поисковиков

| Где | Заголовок (`<title>`) | Описание (`description`) |
| --- | --- | --- |
| Главная | поле в настройках сайта (60) | поле в настройках сайта (160) |
| Страница плитки, поп-ап | поле плитки (60) | поле плитки (160) |
| Если поле пустое | как в 1.4: «Название — сайт» | подпись, иначе первые ~160 знаков текста |

`<h1>` на странице — то, что видит человек: на главной заголовок первого блока Текст (нет такого — название сайта); на странице плитки — название плитки. Остальное SEO (canonical, OG, JSON-LD, sitemap, robots) — как в 1.4.

## 8. Админка

Как в 1.4 (три колонки: дерево, форма, превью; цвета по макету v8). Изменения:

- **Дерево** показывает блоки. Блок Плитки раскрывается, внутри — его плитки. Плитка со страницей раскрывается, внутри — блоки её страницы. Таб раскрывается, внутри — его лента.
- **Добавить блок**: Текст, Фото, Плитки, Карта, Оплата, Услуга, Табы. Недоступные типы — серые с подсказкой («Уже есть на этой странице», «Только на главной»).
- **Добавить плитку** — кнопка внутри блока Плитки.
- **Форма плитки**: убран переключатель «страница / карточка». Есть галочка «Открывать как страницу» (уровень 1). Рядом подсказка: «Сейчас открывается: поп-ап / страница».
- **Поле «Источник фото»** из форм убрано.
- **Редактор фото**: перетаскивание, масштаб, поворот на 90°, сброс. При загрузке рамка сама встаёт по центру и закрывает фото без пустых полей. Рамка — по настройке блока (3:2 или 4:5).
- **Настройки сайта**: адреса, владелец, документы и cookies, «Для поисковиков» главной, выгрузка и загрузка сайта.
- Узел «Режим сайта» удалить.

## 9. Выгрузка и загрузка сайта (согласовано с Вадимом)

Цель: делать однотипные сайты (монастыри, винодельни) копированием готового.

- **Выгрузить сайт** — один ZIP: `site.json` (всё дерево в формате 1.4, раздел 6, с новыми блоками) + папка `photos/` (исходники и параметры кадра).
- Галочка **«Только структура»** — в ZIP блоки и настройки без текстов, фото, координат, ссылок оплаты и реквизитов. Получается пустой шаблон.
- **Загрузить сайт** — в пустую установку: получается копия. В установку с данными — только после подтверждения «Текущий сайт будет заменён», перед этим автоматическая копия базы в `data/backups/`.
- **Выгрузить таб** — ZIP одного таба как отдельный сайт (без блока Табы).
- **Загрузить таб** — добавляется новым скрытым табом.
- Проверки при загрузке — как при сохранении. Ошибка — ничего не записывается.
- Выгрузка и загрузка переносят тексты на всех языках, которые есть в базе.

## 10. Изменения базы (новыми миграциями)

Ориентир. Имена и детали — на усмотрение Вадима, по правилам 1.4 (раздел 8).

1. `elements.type` — добавить `text`, `photo`, `tiles`, `tabs`. Пересоздание CHECK — по правилам SQLite внутри миграции.
2. Блок `tiles` — родитель для `tile`. Колонки настроек: `tiles_size` (`large`/`compact`), `tiles_aspect` (`3:2`/`4:5`), `tiles_kind` (`normal`/`wine`).
3. Плитка: `as_page INTEGER DEFAULT 0`. Колонку `open_mode` больше не читать (оставить для отката).
4. Текст: `title_size` (`l`/`m`/`s`), `body_size` (`lead`/`normal`/`small`); в `element_i18n` — `eyebrow`.
5. Фото: `photo_width` (`full`/`narrow`); подпись — в `element_i18n.subtitle`.
6. SEO: в `element_i18n` — `seo_title`, `seo_description`; для главной — ключи в `settings_i18n`.
7. Табы: блок `tabs` на главной; табы = записи `sections`. `settings.site_mode` больше не читать.
8. `element_i18n.photo_source` — не удалять, не выводить.

**Перенос уже введённых данных** (в той же миграции или скриптом):

| Было | Стало |
| --- | --- |
| `intro` | `text` (заголовок, текст; фото → отдельный блок `photo` перед ним) |
| `outro` | `text` (размер заголовка: обычно) |
| подряд идущие `tile` | один блок `tiles` (крупные, 3:2, обычные), плитки внутри |
| подряд идущие `wine` | один блок `tiles` (компактные, 4:5, вина) |
| `open_mode = page`, есть дети | `as_page = 0` (страница и так из-за детей) |
| `open_mode = page`, нет детей | `as_page = 1` |
| `open_mode = card` | `as_page = 0`; если были скрытые дети страницы — сохранить, они станут видны → проверить вручную |
| `site_mode = sections` | блок `tabs` последним на главной; общее предисловие → блок `text` выше Табов |

Перед переносом — копия базы (как в 1.4). После — проверить сайт по чек-листу раздела 11.

## 11. Критерии приёмки

Проверять в Chrome, Safari (iOS), Firefox на ширине 1280, 768 и 390 px.

**Блоки**
- [ ] Можно поставить 5 блоков Текст подряд — все выводятся.
- [ ] Размеры заголовка и текста меняются тремя вариантами, других нет.
- [ ] Блок Фото: на всю ширину и узкое; на телефоне узкое — на всю ширину.
- [ ] Вторую Карту или Оплату на страницу добавить нельзя, подсказка понятная.

**Плитки**
- [ ] Крупные: 3 / 2 / 1 в ряд. Компактные: 4 / 3 / 2.
- [ ] Вертикальные 4:5 и горизонтальные 3:2 режутся по своей рамке.
- [ ] Плитки ряда одной высоты; значки на одной линии при любой длине текста.
- [ ] Плитка без блоков — поп-ап, значок +. Добавили блок — страница, значок →.
- [ ] Галочка «Открывать как страницу» даёт статичную страницу, значок →.
- [ ] На уровне 2 галочки нет, всё открывается поп-апом.
- [ ] Вина: поля сорт, год, цвет, сладость, цена; цена скрывается переключателем; кнопки «Купить» нет.

**Табы**
- [ ] Блок Табы только на главной, только последним; второй добавить нельзя.
- [ ] Блоки выше Табов видны на всех табах; на адресе страны не видны.
- [ ] Удалили блок Табы (при одном табе) — сайт работает одной лентой без префикса.

**Поисковики**
- [ ] Заполненные поля «Для поисковиков» попадают в `<title>` и `description`.
- [ ] Пустые — заполняются автоматически.
- [ ] Источник фото нигде не выводится.

**Выгрузка**
- [ ] Выгрузка → загрузка в пустую установку даёт тот же сайт.
- [ ] «Только структура» даёт сайт с блоками без текстов и фото.
- [ ] Выгрузка таба → загрузка как отдельный сайт работает.

**Перенос данных**
- [ ] Тестовое наполнение 1.4 после миграции выглядит так же, как до неё.

**Остальное**
- [ ] Чек-листы 1.4 (А12, Б11) по неизменённым частям проходят.
