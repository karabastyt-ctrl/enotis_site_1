# Энотис — сайт #1 (лента)

Движок и админка по спецификации 2.1 (`docs/spec-2.1.md`).
Стек: PHP 8.1+, SQLite, ванильный JS, Leaflet, Cropper.js.
Выкладка: GitHub Actions → FTP на reg.ru.

## Проверка локально

```
php -S 127.0.0.1:8080 -t public public/index.php
```

При первом запросе создаётся база `data/site.sqlite`. Если она пустая, в неё загружается
тестовый сайт из `demo/` («Паломник по Грузии»). Чтобы перезагрузить тестовый сайт,
поменяйте строку в `demo/VERSION`. Папка `demo/` не входит в релиз для клиентов.

Загрузить другой сайт из JSON (формат 3, раздел 12 спецификации):
`php bin/import.php tests/fixtures/sample/site.json`. Своя папка данных: `ENOTIS_DATA=/tmp/x`.

## Админка

Адрес `/admin`. На чистой установке первая страница — «Создайте вход» (логин, почта, пароль).
Забыли пароль: положите в папку `data/` файл `reset-password.txt` с одной строкой — новым паролем (от 8 знаков);
при следующем открытии `/admin` пароль сменится, а файл удалится.
Проверка админки в CI: `tests/admin-smoke.sh http://127.0.0.1:8081`.
