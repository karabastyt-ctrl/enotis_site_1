# Энотис, сайт #1 (лента) — памятка для Claude

- Спецификация 2.1 — `docs/spec-2.1.md`, единственный источник истины. Сначала правим документ, потом код.
  Старые 1.4, 2.0 и список изменений 2.0 — в `docs/archive/`, только для истории.
  Эталоны: `docs/mockups/site-v4.html` (сайт), `docs/mockups/admin-v8.html` (админка); если расходятся со спецификацией, права спецификация. Цвета в макетах старые: цвета только по спецификации 2.1 (разделы 9.1, 10.2).
- Стек: PHP 8.1+, SQLite (PDO), ванильный JS, Leaflet и Cropper.js локально. Без фреймворков и composer.
- Корень сайта — `public/`. Код в `app/`, база в `data/` (не в git). Корневой `.htaccess` — запасной вариант,
  если хостинг не даёт указать корень = `public/`.
- Контент только в базе, с кодом языка. Служебные подписи — `app/lang/{ru,ka,en,fr}.php` (админка — `app/lang/admin/`). Весь вывод через `e()`.
- Изменения базы — только новой миграцией, старые не править.
- Сайт работает без JS.
- Выкладка: `.github/workflows/deploy.yml`, push в main → FTP на reg.ru (секреты FTP_*).
- Проверка локально: `php -S 127.0.0.1:8080 -t public public/index.php`.
- Работаем через ветки и pull request, не напрямую в main.
- Дизайн и контент «Паломника» берём из кода Вадима: gitlab.com/wine-group4/sacros-landing (только как образец).
